# inbox

Raw feature ideas and findings that came from **using** the tools, before they
are worked up into anything. Nothing here is a commitment, a plan, or a spec.

The point of this folder is that findings usually surface while doing something
else entirely — a backup audit, a cull, a trip import — and the alternative to
writing them down here is losing them.

**Lifecycle:** a note lands here → if it survives a read-through it graduates to
`docs/ROADMAP.md` or `BACKLOG.md` with a real shape → the inbox note stays as the
record of where the idea came from and what was actually measured.

Name files `YYYY-MM-DD-short-slug.md`.
